Die Ressortzeile bleibt auf Setup, Ergebnis, Tischen und geteilter Wertung stehen (keiner der fünf Links ist dort hervorgehoben — die Session ist kein Abschnitt); wer mitten in einer Abstimmung einen Link nimmt, bekommt den Dialog „Abstimmung verlassen?“ aus P15b.
